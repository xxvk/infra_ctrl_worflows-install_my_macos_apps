# 国内大模型 API 价格与选型参考（2026-08-22 核对版）

> 本文只比较厂商官方 API，不比较网页会员、Coding Plan、云市场转售、私有化部署或限时赠送额度。
> 价格会频繁调整；上线前必须再次查看链接中的官方价格页。

## 统一口径

- 价格单位均为 **人民币元 / 百万 tokens（MTok）**。
- “输入”指缓存未命中的普通输入；缓存命中价单列。
- 同一模型可能按地域、上下文长度、服务等级或促销活动分档，下表只列中国大陆/全球服务中最常用的公开档位。
- 不能只比较输入价：Agent 和思考模型可能产生大量输出 tokens，实际费用应按下式计算：

```text
费用 = 未缓存输入 tokens × 输入单价
     + 缓存命中 tokens × 缓存价
     + 输出 tokens × 输出单价
     + 搜索、缓存存储、语音等附加费用
```

### 示例成本口径

为了提供一个可复算的数量级，本文使用：**100 万未缓存输入 tokens + 25 万输出 tokens**。
这不是能力或性价比排名，只是价格示例；长思考任务的输出比例通常更高。

### 表格注记

1. DeepSeek 当前官方页面没有按“高峰/空闲”区分 Token 单价。`reasoning_effort` 会改变推理长度和实际输出量，但不应被写成固定的“高峰价格指数”。
2. Qwen 价格按地域和上下文分档明显。表中的 Flash 是 ≤32K 档；Plus 使用核对日页面显示的八折价；Max 使用全球档。不同部署地域不能直接混算。
3. 火山引擎使用“起”表示最低公开档位；上下文、服务方式和缓存存储可能产生不同价格。旧的 `doubao-lite-32k`、`doubao-pro-32k` 不再作为本表主推矩阵。
4. MiniMax M3 与 M2.7 标准档当前恰好同价：M3 的刊例价经官方“永久五折”后为输入 2.10、输出 8.40；M2.7 标准档也是 2.10/8.40。同价不表示能力相同。新项目应默认先测 M3；M2.7 主要用于既有项目兼容或回归对照，因此不在主表重复列出。M3 输入超过 512K 后为输入 4.20、输出 16.80、缓存读取 0.84；M3 优先服务为标准服务的 1.5 倍。
5. Kimi 页面更新较快。调用前应通过官方 List Models API 确认 K2.7 Code 和 K3 的准确 API model ID，不能只按展示名称猜测。
6. 腾讯混元原平台正逐步迁移至 TokenHub；免费额度属于有期限、有限量的体验资源包，不等于永久零成本。
7. 智谱不只有 `glm-5.2`。当前矩阵至少包括免费文本模型 `glm-4.7-flash`、低成本高速模型 `glm-4.7-flashx`、高智能文本模型 `glm-4.7`、文本旗舰 `glm-5.2`、多模态 Coding 模型 `glm-5v-turbo`，另有图像、视频、语音等专用模型。GLM-4.5 等旧系列正在下线迁移，不再作为新项目首选。
8. `glm-4.7` 按单次请求长度分档：输入 <32K 且输出 <0.2K 时为输入 2、输出 8、缓存命中 0.4；输入 <32K 且输出 ≥0.2K 时为 3/14/0.6；输入 32K–200K 时为 4/16/0.8。表中采用更符合 Agent 长回复的第二档。`glm-5v-turbo` 输入 ≥32K 时为输入 7、输出 26、缓存命中 1.8。智谱缓存存储目前限时免费，不能视为永久价格。

## 如何做真正的性价比比较

不存在脱离任务的统一“价格指数”。建议使用自己的请求日志，至少分三类压测：

| 工作负载 | 建议记录 |
| --- | --- |
| 路由/抽取 | 成功率、JSON 合法率、P95 延迟、每千次成本 |
| 日常 Agent | 工具调用成功率、平均轮数、输入/输出 tokens、任务完成成本 |
| 复杂代码/研究 | 一次完成率、人工返工时间、总输出 tokens、搜索等附加费 |

同一批固定任务至少重复 20 次，再比较：

```text
有效任务成本 = API 总费用 / 成功完成的任务数
```

低单价模型如果需要更多轮重试，最终成本可能高于单价更贵但一次完成率更高的模型。

## 面向 Pi 类 Agent 的初始候选

- **低成本路由与清洗**：先测 `qwen3.7-flash`、`Doubao-Seed-2.0-mini`、`deepseek-v4-flash`。
- **日常主力 Agent**：先测 `qwen3.7-plus`、`deepseek-v4-pro`、`MiniMax-M3`。
- **代码与长程任务**：先测 `deepseek-v4-pro`、`glm-5.2`、Kimi K2.7 Code；是否值得使用 K3 应以任务完成率验证。
- **拟人化回复**：不要仅凭厂商品牌判断。用相同人设、记忆和安全约束，对 MiniMax、Kimi、Qwen 等做盲测。
- **联网搜索**：把搜索工具调用费、搜索结果质量和引用正确率单独统计；“模型擅长联网”通常也依赖厂商工具，而不只是基础模型。

## 维护规则

- 每次更新价格时同步修改标题中的核对日期。
- 只使用厂商官方价格页，并保留链接。
- 新增价格必须写清币种、MTok、地域、上下文档位、缓存状态和促销条件。
- 不再使用无法复算的“价格指数”，也不写“95% 能力”“最强”“无可替代”等无测试依据的结论。
