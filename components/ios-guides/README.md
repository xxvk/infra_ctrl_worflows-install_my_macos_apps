# iOS application guides

Operational guides for iPhone/iPad applications, parallel to the macOS
component guides. Each entry in `references/ios-app-catalog.json` links to its
guide here via the `guide` field (e.g. `components/ios-guides/wechat.md`).

These guides cover installation, account scope, verification, and cleanup for
iOS apps. They are **desired-state documentation only**; current installation
status, versions, and device observations belong in machine-local state and
`Private/ios-inventory.json`.
