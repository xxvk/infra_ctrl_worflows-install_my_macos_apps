# 哔哩哔哩

- Install with the official Homebrew cask: `brew install --cask bilibili`
- Homebrew cask source: `https://github.com/Homebrew/homebrew-cask/blob/HEAD/Casks/b/bilibili.rb`
- The cask downloads the official macOS DMG from `dl.hdslb.com`.
- If Homebrew reports `Could not resolve host: dl.hdslb.com`, diagnose before changing DNS:
  `scutil --dns`, `dscacheutil -q host -a name dl.hdslb.com`, `dig dl.hdslb.com`, and `curl -I -L https://dl.hdslb.com/mobile/fixed/pc_electron_mac/bili_mac.dmg`.
- Confirm the direct DNS query and HTTPS request work, then retry `brew install --cask --force bilibili`. Do not use an unverified mirror.
