# みずほ銀行 (Android)

> [!summary] Purpose
> Japan-region core app (2026-08 user selection). Play Store package
> `jp.co.mizuhobank.banking`. Requires a Japanese account.

## Install (Play Store via apkeep)

```sh
apkeep -a jp.co.mizuhobank.banking -d google-play -e '<user@example.com>' -t <aas_token> -o split_apk=true .
adb install-multiple <download-dir>/jp.co.mizuhobank.banking/*.apk
```

## Verification

- `adb shell pm list packages | grep jp.co.mizuhobank.banking` read-back.
- Launch on the Pixel and confirm the visible Japanese account.

## Cross-platform

- iOS equivalent: `jp.co.mizuhobank.bankingapp`; see `references/cross-platform-app-map.json`.

## Cleanup

```sh
adb uninstall jp.co.mizuhobank.banking   # only after explicit confirmation
```
