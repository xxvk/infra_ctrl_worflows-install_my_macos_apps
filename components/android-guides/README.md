# Android application guides

Operational guides for Android applications, parallel to the macOS component
guides. Each entry in `references/android-app-catalog.json` links to its guide
here via the `guide` field (e.g. `components/android-guides/wechat.md`).

These guides cover installation (Play Store / APK), verification, and cleanup
for Android apps. They are **desired-state documentation only**; current
installation status and device observations belong in machine-local state and
`Private/android-inventory.json`.

## Rules

- Play Store installs use `apkeep` with a user-provided OAuth/AAS token; never
  automate or store Google credentials.
- Verify the device serial before install; read-back with
  `adb shell pm list packages`.
- See [`references/android-application-workflow.md`](../../references/android-application-workflow.md)
  for the full lifecycle contract.
