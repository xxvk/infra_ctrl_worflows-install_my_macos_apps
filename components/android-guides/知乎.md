# 知乎 (Android)

> [!summary] Purpose
> core expansion 2026-08 (user selection). Play Store package
> `com.zhihu.android`.

## Install (Play Store via apkeep)

```sh
apkeep -a com.zhihu.android -d google-play -e '<user@example.com>' -t <aas_token> -o split_apk=true .
adb install-multiple <download-dir>/com.zhihu.android/*.apk
```

## Verification

- `adb shell pm list packages | grep com.zhihu.android` read-back.
- Launch on the Pixel and confirm the visible account.
