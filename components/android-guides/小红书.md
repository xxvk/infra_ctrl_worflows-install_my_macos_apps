## Install (Play Store via apkeep)

```sh
apkeep -a com.xingin.xhs -d google-play -e '<user@example.com>' -t <aas_token> -o split_apk=true .
adb install-multiple <download-dir>/com.xingin.xhs/*.apk
```

- `adb shell pm list packages | grep com.xingin.xhs` read-back.
- Launch on the Pixel and confirm the visible account.
